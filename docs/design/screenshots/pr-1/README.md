# PR #1 디자인 비교 이미지

기존 GitHub `develop`의318f31c와 제품 코드32b53d6을 동일한375×844px viewport·DPR1·샘플 데이터로 캡처했다. 전체 스크롤 영역을 포함하므로 콘텐츠 양에 따라 높이가 다르다. Lighthouse가 제공한 WebP 바이트를 그대로 저장했으며 편집·합성·크롭하지 않았다. 각 이미지와 원시 진단의 해시·시각·경로는 [manifest.json](manifest.json)에 기록했다.

`*-before.webp`는 기존 디자인, `*-after.webp`는 PR 디자인이다. 비교 서버의 인증·소켓 fixture는 화면 표시용이며 실제 로그인이나 채팅 전송 결과가 아니다. `home-mock.webp`는 로그인 없는 개발 목 앱의 플로팅 메뉴를 보여 주는 별도 이미지로 전후 비교 데이터에 포함하지 않는다.

아래 값은 같은 조건에서 단발 실행한 Lighthouse Accessibility 점수다. 제품 성능 점수나 WCAG 전체 준수 판정이 아니다.
