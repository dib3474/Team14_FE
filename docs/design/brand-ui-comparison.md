## 1. 기존 디자인의 주요 문제

강한 카드 그림자·확대 hover·두꺼운 선택 테두리가 정보 위계를 분산했다. 앱 폭과 상하단 높이의 직접 정의가 여러 파일에 있었고 Safe Area·채팅 높이 계산도 일관되지 않았다. 긴 기간/주소가 잘리거나 검색 카드 두 열에서 읽기 어려웠다. 링크 안 버튼, 클릭 가능한 div, 이름 없는 제어, 입력 오류 연결과 모달 상태 전환의 초점 처리도 보완이 필요했다. 추천·계정·관리 화면에는 서로 다른 카드·배지·메뉴 표현이 남아 있었다.

## 2. 적용한 디자인 방향

로고·오렌지 Primary·블루 Secondary와20개 팔레트 값을 유지했다. 흰 표면·블루그레이 바탕·어두운 글자, 오렌지 핵심 행동과 블루 보조 안내로 밝고 친근한 안을 만들었다. 기존 안의 아이보리·초록 바탕 및 가로 목록 카드와 구분된다. 새 UI 라이브러리나 의존성은 추가하지 않았다. 구현 규칙과 컴포넌트 수정 위치는 [디자인 규칙](brand-ui-rules.md)에 정리했다.

## 6. 검증과 캡처 신뢰성

- npm run typecheck: 통과.
- npm run lint:0 errors, 큰 스냅샷 경고3건.
- npm run test:16개 파일136개 통과. 기존 선택·필터·스와이프·전송·권한/핸들러와 새 키보드/초점/설명 동작을 확인했다.
- npm run build: 통과. 단일 eager 청크615.43kB, gzip194.95kB로500kB 초과 경고가 남는다. 원본 라우터 구조를 유지했고 임의로 코드 분할을 변경하지 않았다.
- Node capture validator:4개 통과. 로그인 대체·예상하지 않은 단계·내용 미완료를 거부한다.
- 제품 빌드 JS에 비교용 인증 토큰/Provider가 포함되지 않음을 확인했다.

초기 비교에서는 원본 인증 초기화 리다이렉트 때문에 일부 보호 화면이 로그인 화면으로 저장됐다. 그 결과는 모두 채택 대상에서 제외하고 로컬 rejected 폴더로 옮겼다. 이후 비교 전용 Provider와 실제 스타일 enum을 사용하고 최종 origin/path/query·DOM 내용·폭이 맞을 때만 PNG를 게시했다. 검색 내용 검사 누락과 Chrome NO_FCP 실행도 거부 후 재수집했다. 점수가 높다는 이유로 다른 화면을 결과로 채택하지 않았다.

독립 코드 리뷰의 Important1건은 업로드 중 제어 비활성화/성공 전환에서의 모달 초점 이탈이었다. 합성 UI 전환 테스트2개 RED→GREEN과 전체 테스트로 수정했다. 이는 실제 S3 업로드 E2E 인증 결과가 아니다. 이후 작성자가 실제 캡처를 확인했으며 두 번째 코드 리뷰는 하지 않았다.

실제 캡처는 `superpowers/comparison/screens/`, 원시 진단은 reports/에 로컬 보존했다. 대표 파일은 comparison-hub-1280.png, new-home-375.png, new-list-375.png, new-pick-375.png, new-history-375.png, new-chat-375.png, new-settings-375.png다. 다른 환경에서 보려면 자료를 별도 공유하거나 도구로 다시 생성해야 한다.

## 7. 남은 과제와 제약

- 원본 잠금 파일을 유지했으므로 최신 npm 감사는28건(critical5/high17/moderate5/low1)이다. 이전 브랜치의 보안 업데이트는 새 안에 포함하지 않았다. 실제 배포 전 별도 반영이 필요하다.
- 원본 ProtectedRoute의 초기 인증 타이밍과 기존 로딩/집계 경계는 보존했다. 비교용 인증을 제품 인증 수정으로 해석하지 않는다.
- 실제 OAuth·S3·STOMP·iOS/Android 물리 키보드·Safe Area·스크린리더 조작은 인증하지 않았다. 채팅 viewport는 DOM/이벤트 테스트와 정적 렌더 근거다.
- 자동 접근성100점은 WCAG 전체 준수 판정이 아니다. 실제 장치와 보조 기술에서 추가 검토가 필요하다.
- LCP·INP 및 배포 후 실사용자 성능은 이번에 측정하지 않았다. 라우트 분할/이전 보안·기능 개선의 통합은 디자인 선택 후 별도로 판단한다.
- 최종 디자인/측정 문서는 작성자가 코드·링크·수치를 대조했다. 별도 독립 문서 리뷰는 없다.
