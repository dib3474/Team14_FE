FestaPick독립 디자인 비교

기존 개선안은 보존하고, develop의 원래 디자인에서 새로 개선한 안을 나란히 비교합니다.
동일한 샘플 데이터와 로그인 상태를 사용합니다. 실제 OAuth·업로드·STOMP 전송은 수행하지 않는 로컬 프리뷰입니다.

뷰포트

각 프레임 안에서 스크롤하거나 지역·카드·메뉴를 선택할 수 있습니다. 넓은 뷰포트는 화면에 맞게 축소 표시하며, ‘직접 열기’에서 실제 크기로 확인할 수 있습니다.

비교 포인트

기존 개선안: 지도·얇은 활성 표시 푸터·가로 목록 카드.
새 개선안: 흰색·블루그레이 표면, 포스터 중심 카드, 오렌지 핵심 행동과 블루 보조 안내, AI PICK·계정·설정까지 이어지는 공통 규칙.

동일 조건과 남은 검증 범위
  • 포스터·제목·일정·리뷰·공지·사용자는 세 안에 같은 값으로 제공됩니다.
  • 검색 결과 프리뷰의 q는 비교용 입력 초기화이며 실제 제품의 URL 검색 기능 추가가 아닙니다.
  • 지도 핀 위치와 지역 목적지, 기존 API·업무 훅은 새 안에서 보존했습니다.
  • 새 안은 원본 develop의 업무 동작을 유지하므로 이전 브랜치에서 추가했던 리뷰 페이징·검색 즉시 제출 등이 같다는 뜻은 아닙니다.
  • 화면 캡처는 실제 Headless Chrome 렌더입니다. 접근성 자동 점수와 실기기·실제 백엔드 통합 검증은 구분합니다.
  • 빈 결과/오류 메뉴는 샘플 API 상태를 바꾸며 실제 서비스에는 영향을 주지 않습니다.
